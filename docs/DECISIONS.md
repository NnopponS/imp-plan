# Decisions
- Mind Arena branding; use devils-arena as the GitHub Pages mount only once the namespace has been confirmed.
- Local alpha first, public Pages only after agreed release gates; manual Actions trigger to prevent accidental publication.
- No standalone promotional site, paid service, optional model runtime, copied artwork, or mandatory account.
- Scope every release and claim to tested behavior. Preserve exact rule gaps rather than claiming official fidelity.

Superseding the provisional brand: owner chose a discoverable name similar to the show. Public-facing name is The Devil’s Plan Arena, paired with an explicit unofficial fan badge and original assets. Package/workspace names remain unchanged to preserve builds.

Latest owner decision: Imp Plan is the standalone brand; public repo and Pages use imp-plan, with each tested milestone pushed publicly. Attribute The Devil’s Plan as inspiration, not as the product name. Ship clearly labeled alpha milestones.
