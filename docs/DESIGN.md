# Imp Plan: visual direction
An unofficial fan arena with its own visual identity. Use the show name for discoverability, not the Netflix wordmark, key art, layouts, or promotional photography. The visual reference is the series' tense, physical strategy-table atmosphere, adapted to a light editorial palette rather than streaming dark mode. Reference: https://about.netflix.com/en/news/the-devils-plan-dead-again-main-trailer

Materials: aged brass, ivory limestone, blackened burgundy, oxidized teal. Scene: an original faceted arena token over a circular inlaid board. Four individual studio-rendered game objects replace generic diagrams. Keep form controls above the fold and game state high-contrast. Add restrained orbit, scene entrance, hover lift, placed-stone and score animations. Respect reduced-motion. Keep all assets local, with no new runtime dependency.

Verification: production asset URLs, 390px and desktop layouts, brand/title visible, disabled motion when requested, full prior game/lobby tests.

Site navigation reference: https://quoridorgame.com/en/. The useful pattern is season-first navigation and a separate rules action. The app uses its own visual system, renders, and copy. Linking is ordinary HTML across three static season pages; those pages also carry crawlable initial summaries and separate canonical links. No new tracker or runtime service.
