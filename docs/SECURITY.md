# Security and boundaries
The room code is a locator, not strong security. Keep it among trusted friends. Hosts can lock joins or remove lobby seats and can read or manipulate game state from their own browser. Peer connections may expose IP/network information. No app accounts, analytics or database. Connection-scoped commands, strict incoming shape, bounded message sizes, capped connection attempts, per-connection message throttling, revision and request filtering, and rotating 128-bit tab resume capabilities. Tokens never appear in invites; guest sessionStorage is scoped to the tab. React renders nicknames/chat as text. Old board ownership and active bids are excluded from public snapshots. Packets from an adversarial host are not a trusted security boundary; trusted-friends only. There is no host migration.
