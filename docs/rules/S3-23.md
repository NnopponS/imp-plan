# S3-23: Exile Rectangle Counting

Category: Exile  
Seat range in handoff: 1–16  
Broadcast verification: partial  
Fan implementation: playable alpha, standalone or in a private room.

## Fan rules

Three 90-second grids (6×8, then 8×8 twice). Count all axis-aligned rectangles whose signed numbers total zero. Each cell and square may qualify. All seats see the same board and lock one private answer per grid. Most correct wins; equal scores use cumulative submission time on correct answers, then share the result if still tied. One seat may practice. The season exile bracket and elimination/return rules are not implemented. No bots are needed for this puzzle.
