# S3-03 · Count the Rectangles

**Status:** Playable fan adaptation (1–16 human seats; solo supported). Original broadcast parity is not verified.

- See the official [Netflix series page](https://www.netflix.com/title/81653386), S3 episode 1, for the broadcast source and the [report on the first-round clarification](https://www.chosun.com/english/kpop-culture-en/2026/11/13/NA3TOBWRBZDQXO6CQDDUG4ORGM/) for a secondary research lead. Verify whether the broadcast rules define grids, retries, and outcomes differently before claiming parity.
- Imp Plan is a four-grid independent challenge. Count axis-aligned nonempty rectangles with the displayed target sum, including single cells and squares. Signed tile values are allowed. Grids grow from 4 × 5 to 7 × 7, with 45 seconds and one private answer per grid.
- Tile highlighting is a local scratch aid and does not calculate the answer. Each exact answer earns one point. Total time across correct answers breaks point ties, then ties are shared. The host uses two-dimensional prefix sums; the tests cross-check against exhaustive brute force.
