## Fan table

Every round starts with an empty 6 × 6 grid. Place the next letter’s two ends in any unused cells. The other player may accept and take their placement, or challenge the entire layout. Routes use up/down/left/right steps, do not revisit cells, cannot go through another pair’s terminal, and cannot share any cell. Unused space is allowed; there is no minimum route length beyond connecting the two terminals.

On a challenge, an exact result awards the round: if all routes fit, the last placer wins and the witness is displayed; if they cannot fit, the challenger wins. Letting the response timer expire automatically challenges. Letting the placement timer expire loses the round. The default for each placement or response is 45 seconds and the host can configure it before the match.

After six accepted pairs, an impossible layout awards the round to the opponent of the first accepted placement that made the layout impossible. For a feasible layout, both players have 90 seconds to trace all six paths locally. Tapping or using the keyboard builds each route one cell at a time. The first valid full submission received by the host wins. If neither submits a valid proof, the round is drawn. A bot also uses only the shared position. Easy and Standard mainly differ in when they submit a race proof (62 and 43 seconds into the race). Hard favors more central endpoints and can submit from 26 seconds.

The search has a fixed work budget. An inconclusive search rolls back the most recent pair and lets the placer try again once per round. Another inconclusive result draws the round; no point is awarded from search exhaustion. The opening player swaps between rounds. First to two wins ends the match. After three rounds, more wins takes the match; equal wins is a draw.
