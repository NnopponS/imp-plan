# S3-18: Spot the Difference

Exile · 1–16 humans · playable fan adaptation · broadcast rules unverified

Each player compares the same two generated specimen trays and privately marks changed regions. There are 5–8 differences across 12 labeled regions, with at most one change per region. Differences cover shape, ink/pattern, horizontal position, size, and presence. Mark a region by tapping either tray or by comparing its text descriptions and using the named keyboard button. Zooming pans the trays together and does not change a region ID. Each mark is final.

Everyone has 90 seconds; a wrong mark takes five seconds off that player's remaining time. The host checks the region ID, clocks and repeat marks. Players stop when they find every difference or their own time runs out. The match ends when all players have stopped. Rank by differences found, then elapsed time to the last correct mark plus all incurred penalties. Exact ties share rank; a table with no finds has no winner. Results display the correct regions and adjusted times. Solo uses the same rules. There are no bots or exile-return effects.

The text and image views describe the same properties. Text comparison can make this speed puzzle easier; agree on the same format before competitive play. Ink changes also change line patterns. Marks and times are private until results, but clients receive both images; this is an honor-system deduction challenge, not cheat-resistant competition. Host clock and input latency also matter.
