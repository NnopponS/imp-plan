# S3-20: Loop Fence Puzzle

Exile · 1–16 humans · playable fan adaptation · broadcast rules unverified

All players receive the same 5×5 clue grid and draw on private copies. A number counts the edges on its cell's perimeter. Zero forbids lines on all four sides. Blank cells have no clue. Each edge can be empty, a fence line, or crossed out as a note. Selecting the current mark again removes it. Crosses never count as lines.

Make one closed loop with at least four edges. Every touched intersection must have exactly two incident lines, all lines must form a single connected component, and every shown clue must match. The host checks the drawing on each change, locks a correct entry, and records its completion time. The game stops when everyone solves or four minutes pass. Solvers rank first by earliest time; other players rank by satisfied clues less one for each intersection with invalid degree, with a floor of zero. An empty board scores zero. Exact ties share rank. The solution is viewable only after the round ends. Solo follows the same rules; there are no artificial opponents.

## Puzzle certification

Three authored continuous outlines provide a bank of 24 variants through rotation/reflection. Clues are the perimeter counts, with eight removed on each outline. The proof search propagates shown clues and degree constraints (0 or 2), then branches on any undecided edge and checks whole-loop connectivity. Tests exhaust all 24 patterns without reaching the node cap and compare the unique solution with the authored outline. This is a fixed 5×5 fan pack, not an 8×8 editor or unlimited generator. The source and client code contain the authored outlines; private room views withhold the solution and other players’ work, but the game assumes honest participants.
