## Fan rules

1. Start with 12 fictional chips. Each seat with chips pays one ante. A 44-card deck contains one of each number from 0 to 10 in four suits. The first number is private, the next two are public. A hand of four zeroes has its last face replaced by an undealt nonzero number.
2. The starting seat rotates each deal. On your wager turn you may check if nobody has bet, call to match the current wager, raise the total, or fold. Each pass caps the wager at three chips or the smallest eligible stack at the start of the pass, whichever is lower. A raise reopens the decision for other active seats. The second pass begins when wagers match and the third open number appears. If only one seat is left, it receives the entire pot and no hidden cards are shown.
3. After both passes, arrange the four numbers and use exactly one +, −, and ÷ in any order. Divide before adding or subtracting. Division by zero is invalid. Submit privately for Low (distance from 1), High (distance from 20), or Swing (a different arrangement per lane).
4. At reveal, each lane uses exact distance. Tied High scores favor the largest physical card; tied Low scores favor the smallest. Compare number first, then suit in ascending order Slate, Copper, Silver, Gold. Swing only qualifies if it leads both lanes in the initial comparison. Failed Swing entries are removed before awarding the lanes. A single winning lane takes the full pot; different lane winners split it with an extra chip going to High. If nobody qualifies, all contributions return.
5. A timed-out wager checks if the seat owes nothing or folds otherwise. Missing the seal deadline forfeits that deal's entry. Out-of-chip seats watch later deals. Review advances on request or after 20 seconds. The match ends after four deals or when fewer than two seats still have chips. Largest stack wins; equal leaders share the result.

## Implementation and art

- Host-authoritative 2–8 seat table, one common ledger, private per-seat input and secure online shuffles. The browser host itself can inspect its own process, so this is a trusted-person party game, not cheat-proof multiplayer.
- Cover, dial plate, cards, and worked example are original vector artwork created for Imp Plan. No show artwork, clips, transcript text or sound in the game.
- Coverage includes exact arithmetic, both wagers, secrecy, split and Swing settlement, stale/malformed host commands, bot turns, result, and peer and offline browser play. Local signaling evidence is not a test of a hosted PeerJS relay.
