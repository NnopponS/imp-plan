## Episode evidence

The [unofficial English transcript of Season 1 Episode 9](https://www.springfieldspringfield.co.uk/view_episode_scripts.php?episode=s01e09&tv-show=the-devils-plan-2023), approximately lines 1560–1648, describes a five-round cooperative face-memory challenge and a rehearsal. Faces appear one at a time for three seconds. The fastest correct buzz on a repeat clears that round and earns one Piece. A false buzz adds to the team penalty, but play continues until the eleventh error. Failing to buzz before the repeat disappears ends the match. The team succeeds only if all five rounds are cleared.

## Rules in Imp Plan

1. The host opens each round when the table is ready. A two-second countdown starts before the first portrait.
2. Watch the shared portrait gallery. In a private match, each face remains visible for three seconds. Buzz only when the current face has appeared earlier in the same round. On a keyboard, Tab to the buzzer and press Enter/Space, or press **B** while focus is in the gallery (not while typing).
3. A false buzz costs one shared error. Each person can buzz once per face. Continue with the same timer; the eleventh error ends the match.
4. If two people buzz on the repeat, the first valid command received by the browser host wins the one fictional Piece. The closing endpoint is exclusive. A stale or disconnected command cannot claim the following frame. If a repeat times out, the game ends.
5. Five successful rounds clear the match. Offline practice uses one shorter round, four-and-a-half-second portraits and no Piece awards.

The generated deck uses 32 original illustrated avatars and a new private seed per match. The countdown, variable lengths, seat support, clock/packet arbitration, and practice differences are digital fan rules. The browser host is authoritative; local/room play is casual and is not cheat-proof. Players on slow connections may see less of a frame. The board offers live portrait descriptions and a reduced-motion countdown. No real cross-network session or complete broadcast rules are claimed.
