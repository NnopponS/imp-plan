# S1-06: Word Tower

Prize D3 · 1–16 humans · playable English fan adaptation · broadcast rules unverified

The team gets one themed tray of letter tiles and three to six empty columns. Read each word from top to bottom. Pick a tile and add it to a column, return it to the tray, or swap it with another placed or unplaced tile. Columns stay compact, with at most eight slots. Each tile has its own ID, including duplicate letters. The turn owner prepares up to two edits, then commits them together or passes. Play rotates clockwise. Drafts stay local; the host validates the batch before updating the shared tray and columns.

Clear the tower by using all tiles exactly once in distinct valid theme words, in any column order. Any valid arrangement from the pack counts, not just the generator's words: a deal with TONE can also accept NOTE if it satisfies the remaining constraints. The challenge ends at four minutes or after 3×players + 18 turns, whichever comes first. An incomplete result reports distinct valid words, then tiles used. This is one shared team result, not a race or per-player score. Solo uses the same controls without a waiting partner.

The versioned `en-1` list was authored for this project. Four themes contain 16 entries each: Music, Garden, Weather and Kitchen. These 64 selected words are not a general-purpose dictionary. Every board starts with tiles from a valid set of distinct words, guaranteeing at least one solution; player count controls the number of columns. At results, an example arrangement is available. The example is not projected during play. The pack is visible in source; there is no attempt to prevent external word lookup. No translation pack, bots or prize carryover are included.
