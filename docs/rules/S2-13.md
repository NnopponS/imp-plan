# S2-13: Big Small

Season 2, Day 7 final (Episode 12). Two seats. Playable fan table; broadcast verification remains partial.

## Fan table

1. Both seats start with ten fictional chips and their own 0–10 cards. A separate seeded 1–9 reference deck belongs to each seat.
2. The dealer opens the duelist’s next reference. The duelist seals an unused card and a Big or Small call. Only its owner sees the seal contents until the reveal.
3. The bettor sees only the reference and the face-down card. They predict Big or Small and stake one to three chips, bounded by their stack.
4. Compare the cards. A correct duelist call earns the absolute gap; an incorrect call earns nothing. The bettor gains the stake if right and loses it if wrong. A tie changes neither stack.
5. The played card and reference leave the set. Review the round, then swap roles. Emptying either stack ends the game; otherwise evaluate stacks after eighteen rounds.
6. Larger stack wins. If regulation ends tied, play a fresh two-round set at ten chips each with the other seat opening. A second tie is a draw.

Practice fills the other seat with a local bot. Party supports exactly two occupied seats and does not use a tournament wrapper. Neither format has a timer. Chips carry no value.

The browser host handles all moves and draws. A guest sees the current reference and settled cards, not the host’s current sealed card or future references. A malicious host can inspect its browser’s authoritative state; parties are for trusted friends.
