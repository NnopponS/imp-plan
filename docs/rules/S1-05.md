# S1-05 · Secret Number
**Playable Main Match adaptation for 3–16 seats.** Solo practice fills with two bots.

The [official Netflix listing](https://www.netflix.com/title/81653386) is the episode reference (S1E5). Secondary reporting describes number cards and ticket-based mathematical contacts but also describes mechanics not used here, such as the zero ticket. Exact broadcast scoring and clue rules are not claimed.

Each seat receives an unseen distinct 1–100 card. In each of four contact rounds, two seats can agree on one matching ticket and receive a private shared clue: exact sum, product last digit, integer quotient (larger divided by smaller, rounded down), or absolute difference. Each seat starts with two of each ticket at 3–5 players, one otherwise. Four virtual chips allow at most two replenishments. Offers expire between rounds. The private notebook filters possible own values against the available pair clues; it is not a global solver.

Final guesses are private: one own value and up to two other seat values, with 90 seconds to submit. Own exact +4; other exact +2; other incorrect −1, skipped 0. All values are revealed only at the result. The database-free host is trusted to validate and privately project clues. Bots use only their own view.
