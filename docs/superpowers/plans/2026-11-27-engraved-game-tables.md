# Engraved Game Tables Implementation Plan

**Goal:** Bring the hand-drawn visual language of the catalog into all currently playable tables without moving or covering controls.

**Architecture:** Reuse the 30 original individual game engravings as small table marks. Choose a material by what actually gets played on the table and draw original printmaking vectors for the border and surfaces. Give selected game controls a visual craft pass without replacing any labels, hit areas, state or keyboard interactions.

- [ ] Prove that actual open practice tables lack their respective engravings and material surfaces.
- [ ] Add shared engraved live-table treatment, including Blind Gomoku's separate renderer; suppress nonessential marks in focus mode.
- [ ] Add custom marks to established puzzle controls; never obscure the timer, symbols or cards.
- [ ] Verify real matches across desktop, short portrait and short landscape, test all 30 practice entries, inspect screenshots, then run the repository tests and Pages deployment checks.
