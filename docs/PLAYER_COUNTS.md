# Imp Plan: supported fan-table sizes

“Practice” describes the browser’s local roster. Additional seats there are bots, never other devices. In Party, counts include the host and any supported bots. These are game limits for this implementation, not episode cast sizes.

| Game or variant | Party players | Local practice | Why |
|---|---:|---:|---|
| Blind Gomoku, Nine Men’s Morris, Point Gomoku, Equation Lights, Wall Go | 2–4 | 1 human + 1 bot | Two on each board; tested rotation for larger rooms. Four keeps the league finite (12 legs). |
| Bagh Chal | 2 | 1 human + 1 bot | One pair plays both roles. |
| Color Link | 2 | 1 human + 1 bot | Pair placement, opponent challenge and private proof race form one two-player series. |
| Heavy 13 | 2–7 | 1 human + 1–6 bots | Native seven-player inventory and circular placement. |
| Balance Mancala | 2–8 | 1 human + 1–7 bots | One growing shared board; tested through eight. |
| Laying Grass (S1) | 2–12 | 1 human + 1–11 bots | Shared board scaled and tested through twelve. |
| Lay the Grass (S3) | 2–16 | 1 human + 1–15 bots | Tested four-round draft and trade engine at 16. |
| Remove One, Secret Number | 3–16 | 1 human + 2–15 bots | Lowest unique / multiple ticket counterparts. Hands and ticket encoding support sixteen. |
| Time Auction: sealed bids | 2–16 | 1 human + 1–15 bots | Simultaneous submissions plus independent credits, tested through sixteen. |
| Time Auction: Hold & release | 2–16 humans | Not available | Native human-only continuous holds. |
| Memory Poker: episode-style duel | 2 humans | Not available | Two private picks per seat and three shared cards; exact duel only. |
| Memory Poker: fan table | 2–16 humans | 1 human | Private picks and shared point resolution, not a duel wrapper. |
| Knight’s Tour, Hexagon, Count the Rectangles, Count the Cubes, Exile Rectangle Counting, Divine Test, Secret Code, Equation Pyramid, Spot the Difference, Loop Fence Puzzle, Symmetrical Puzzle | 2–16 humans | 1 human | Private/simultaneous answers, grids or marks, with scalable scores. |
| Montage | 2–16 humans | 1 human | Native timed everyone-can-buzz party mode and a separate unscored practice. |
| Piece Puzzle | 2–4 humans | 1 human | One piece tray with turn control after each action. |
| Scale Game | 2–6 humans | 1 human | Shared 12-use balance, with opportunity for two turns at full capacity. |
| Fragments of Memory | 2–8 humans | 1 human | Rotating respondents; gets a turn each in the smallest configured question set if the round does not end early. |
| Word Tower | 2–8 humans | 1 human | A shared word board under a short four-minute clock. |

The default party starts on Blind Gomoku with two places. Select Tournament to seat 3–4 on alternating two-player boards, or choose another game before inviting a larger group. Switching game or variant does not kick anyone; if there are too many existing seats, the host must remove extras (including any offline reserved seats) before switching. Existing players can still reconnect to locked/full tables using their token.
