# Imp Plan: live-table visual parity audit

**Status:** Read-only audit of all 30 playable entries in `src/catalog.json` and their actual React controls. Below is an implementation and acceptance checklist; nothing in a row is claimed shipped. Public-reference checks cover all 13 Dice Devil Play cards, their rule pages, and the reachable Wall Go local scene. They are public-HTML observations, not playthroughs, screenshots, or verification of the TV rules. Some JavaScript modes stay on the landing route; Memory Poker practice and Bagh Chal local subroutes were unavailable to the web reader. No private files are embedded. Preserve Imp Plan’s actual rules and original visual identity.

## Release priorities

1. **Complete in-progress motions, then repeat with next distinct device:** Morris capture groove, Fence rope edge tool, Knight legible hop/undo are already assigned. Follow with Bagh Chal (letters to carvings), Secret Number (forms to exchange tickets), and Scale (final dropdowns to calibration tokens). These remove functional reading burden rather than adding chrome.
2. **Prove the phase before embellishing:** finish two true multi-client flows for private draft/reveal (Auction and Memory Poker) and one offline nontrivial run (Hex, Fence, or Piece). For each, verify actual accepted events and rejected moves. Decorative feedback must never depend on unrevealed peer data.
3. **Use different centerpieces, one system:** etched buttons, contrasting focus, small help and clear typography can be shared; Bagh’s wooden animal, Hex’s brass seals, Spot’s paired paper trays, and Heavy 13’s stacked stone must not be interchangeable.
4. **Acceptance before any parity claim:** test 320×568 portrait, 844×390 short landscape, and 1440 desktop; keyboard/touch, reduced motion, no overflow, fresh-first-turn legibility, no duplicate paints, real match/replay as appropriate. Compare local assets and 4× CPU trace before/after, not art size alone. Collect a screen of each family’s real current action and distinguish an isolated proof from deployed Pages.

### Engraved tables
The 30 playable games use their individual catalog engraving inside their live play surface as well as on their cover. Material tones follow the physical action: lacquer, brass, felt, oak, ink and vellum. The table finish is shared across families; this is not a substitute for the individual control and artwork work listed above. Point Gomoku's two stone faces differ by engraved shape as well as color; the live cabinets, workbench rulings and selected puzzle controls have original illustrations. Art is non-interactive, and table marks disappear in Board Focus. Match results keep their existing readable backgrounds.
